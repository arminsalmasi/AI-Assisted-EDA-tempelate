# Figures Directory (`report/figures/`)

This directory is used to store output visualizations, plots, and charts generated during the exploratory data analysis (EDA) and model validation phases.

## Guidelines
- Export figures in high resolution (e.g., DPI=300 for PNGs, or using vector graphics like PDF/SVG).
- Name figures descriptively to correspond to notebook sections (e.g., `01_customer_demographics_distribution.png`).
