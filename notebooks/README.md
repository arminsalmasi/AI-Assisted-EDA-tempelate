# Notebooks Directory (`notebooks/`)

This folder contains Jupyter notebooks used for exploratory data analysis (EDA), prototyping, and experimental modeling.

## Best Practices
- Name notebooks sequentially (e.g., `01_data_exploration.ipynb`, `02_model_prototype.ipynb`) to establish a clear chronological analysis flow.
- Keep notebooks clean, documented, and run them using the project's virtual environment `.venv`.
